# مكتب آفاق الإنجاز العقاري

موقع عقاري ثابت يُستضاف **مجاناً وبشكل دائم** عبر **GitHub Pages**، مع بوت تيليجرام يرفع العروض والصور تلقائياً إلى الموقع.

## 🌐 الموقع العام (دائم ومجاني)
الرابط: https://abonasr0907-beep.github.io/-/

الموقع ثابت بالكامل (HTML/CSS/JS) ويُنشر تلقائياً عبر GitHub Actions عند كل تحديث.

## 🤖 البوت — الرفع التلقائي للوسائط (الحل الجذري)
البوت في مجلد `bot/`. عند إضافة عرض جديد:
1. يصنّف العرض تلقائياً (مزرعة/استراحة/أرض سكنية) ويحفظه محلياً.
2. **يرفع الصور + `offers-data/offers.json` إلى المستودع عبر GitHub API** (`bot/github_sync.py`).
3. هذا الرفع يُعاد نشر GitHub Pages تلقائياً → **تظهر الوسائط في أقسامها الصحيحة على الموقع العام فوراً**.

> يتطلب الرفع العام ضبط متغير البيئة `GITHUB_TOKEN` (توكن بصلاحية `repo`) في خدمة استضافة البوت.

### إخفاء البوت عن العامة
البوت للاستخدام الإداري فقط: زر/رابط البوت غير معروض في الصفحات العامة، ولوحة `admin.html` محمية بكلمة مرور ومستثناة من الفهرسة (`robots.txt`).

## 🚀 تشغيل البوت دائماً (استضافة مجانية)
الأبسط: **Koyeb** (مجاني، لا ينام، إعادة نشر تلقائية من GitHub):
1. سجّل بـ GitHub على https://app.koyeb.com
2. أنشئ خدمة من مستودع GitHub هذا
3. Build: Dockerfile (موجود) — Start: تلقائي
4. أضف متغير بيئة: `GITHUB_TOKEN` = (توكن بصلاحية repo من https://github.com/settings/tokens)
5. انشر — البوت يعمل 24/7 ويرفع العروض للموقع تلقائياً

## 📁 البنية
- صفحات الموقع في الجذر (index.html, farms.html, ...)
- `css/` `js/` — التنسيق والتفاعل
- `offers-data/offers.json` — بيانات العروض
- `images/bot/` — صور العروض المرفوعة
- `bot/` — البوت + `github_sync.py` (المزامنة)
- `.github/workflows/static.yml` — النشر التلقائي إلى Pages
- `Dockerfile` — لاستضافة البوت

## 🔍 SEO
- `sitemap.xml` و `robots.txt` يشيران للرابط الدائم
- أرسل الموقع لـ Google Search Console: https://search.google.com/search/console
