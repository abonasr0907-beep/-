# مكتب آفاق الإنجاز العقاري — الموقع الإلكتروني

موقع عقاري ثابت (HTML/CSS/JS) يستضاف **مجاناً وبشكل دائم** عبر **GitHub Pages**.

## ✅ الاستضافة الدائمة (GitHub Pages)

الموقع موقع ثابت بالكامل ولا يحتاج أي خادم مدفوع. يُنشر تلقائياً على GitHub Pages عند كل دفع (push) إلى فرع `main`.

**الرابط الدائم:** https://abonasr0907-beep.github.io/-/

### خطوة تفعيل لمرة واحدة فقط (مهمة)

يجب تفعيل GitHub Pages **مرة واحدة** من إعدادات المستودع:

1. افتح: https://github.com/abonasr0907-beep/-/settings/pages
2. تحت **Build and deployment → Source** اختر: **GitHub Actions**
3. احفظ. سيبدأ سير عمل النشر (`Deploy to GitHub Pages`) تلقائياً وينشر الموقع.

بعد هذه الخطوة، يصبح الموقع حياً على الرابط الدائم أعلاه، ويتجدّد تلقائياً مع كل تحديث للكود.

## 🤁 البوت (Telegram)

البوت في مجلد `bot/` وهو مستقل عن استضافة الموقع. يمكن تشغيله على أي بيئة Python ثابتة عند الحاجة (محلياً، أو خادم، أو خدمة سحابية). البوت يكتب العروض في `offers-data/offers.json` والصور في `images/bot/`، ويشير إلى الموقع بالرابط الدائم.

## 📁 البنية

- `index.html` وصفحات الموقع الأخرى في الجذر
- `css/` و `js/` — التنسيق والتفاعل
- `offers-data/` — بيانات العروض (JSON)
- `images/` — الصور والشعارات
- `bot/` — بوت تيليجرام
- `.github/workflows/deploy.yml` — سير عمل النشر التلقائي إلى GitHub Pages
