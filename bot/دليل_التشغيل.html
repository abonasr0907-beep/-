مقدمة: لماذا يتوقف البوت؟

بوت التيليجرام يعمل بطريقتين: الاستطلاع (Polling) والـ Webhook. في وضع الاستطلاع، يحتاج البوت إلى أن يعمل بشكل متواصل ٢٤ ساعة ليتمكن من استقبال الرسائل. إذا توقف البرنامج أو نام الجهاز، يتوقف البوت عن الرد. في وضع الـ Webhook، يرسل تيليجرام الرسائل إلى عنوان ويب (URL) ثابت، فلا يحتاج البوت للعمل بشكل متواصل — يكفي أن يستيقظ عند وصول رسالة.

المشكلة الرئيسية في الاستضافات المجانية هي أنها تُوقف البرامج الخاملة بعد فترة من عدم النشاط. الحل الأمثل هو استخدام وضع Webhook مع استضافة تدعم الاستيقاظ التلقائي عند وصول الطلبات.

🚀 الحل الأول: Render مجاني الأفضل

Render هي منصة استضافة سحابية تقدم خطة مجانية تدعم تطبيقات Python مع Webhook. البوت مصمم مسبقاً للعمل معها بوضع Webhook.

المميزات

مجاني بالكامل في الخطة الأساسية، يدعم Webhook (البوت يستيقظ عند كل رسالة)، لا يحتاج إلى تشغيل مستمر، يدعم متغيرات البيئة (Environment Variables) لحفظ التوكن بشكل آمن، ويتكامل مع GitHub مباشرة — أي تحديث في الكود يُنشر تلقائياً.

الخطوات

  1. ادخل إلى https://render.com وسجّل حساب جديد (يمكن التسجيل بحساب GitHub).
  2. اضغط New + ثم اختر Web Service.
  3. اربط حساب GitHub واختر المستودع abonasr0907-beep/-.
  4. في إعدادات الخدمة:
    Name: afaq-bot Runtime: Python 3 Build Command: pip install -r bot/requirements.txt Start Command: python bot/bot.py Instance Type: Free
  5. في قسم Environment Variables أضف المتغيرات التالية:
    BOT_TOKEN = 8629398802:AAE2ndFy06GfV8qSQpd-cOKDccPUt_G05Os GITHUB_TOKEN = (ضع توكن GitHub الخاص بك هنا) WEBHOOK_URL = https://afaq-bot.onrender.com ADMIN_IDS = 7746757675
  6. اضغط Create Web Service وانتظر دقائق حتى يكتمل البناء.
  7. ستحصل على رابط مثل https://afaq-bot.onrender.com — انسخه.
  8. اضبط رابط الـ Webhook في تيليجرام:
    https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://afaq-bot.onrender.com/webhook
  9. أرسل أي رسالة للبوت في تيليجرام — يجب أن يرد فوراً!
💡 ملاحظة مهمة: في الخطة المجانية، ينام البوت بعد 15 دقيقة من عدم النشاط. عند وصول رسالة جديدة، يستيقظ تلقائياً (يستغرق 30-50 ثانية لأول رسالة). هذا طبيعي ومجاني تماماً.
☁️ الحل الثاني: Koyeb مجاني

Koyeb منصة استضافة سحابية بديلة لـ Render، تقدم خطة مجانية مع تشغيل مستمر بدون نوم.

الخطوات

  1. ادخل إلى https://app.koyeb.com وسجّل حساب جديد.
  2. اضغط Create Service ثم اختر GitHub.
  3. اختر المستودع abonasr0907-beep/- والفرع main.
  4. في الإعدادات:
    Builder: Buildpack Build Command: pip install -r bot/requirements.txt Run Command: python bot/bot.py Port: 8443
  5. أضف متغيرات البيئة نفسها المذكورة في حل Render.
  6. اضبط رابط الـ Webhook كما في الخطوة 8 من حل Render.
  7. انتظر حتى يكتمل النشر وجرّب البوت.
⚠️ تنبيه: قد تتغير سياسة Koyeb المجانية من وقت لآخر. تأكد من مراجعة الخطط الحالية قبل الاشتراك.
🚂 الحل الثالث: Railway محدود مجاني

Railway منصة استضافة سريعة وسهلة، تقدم رصيد مجاني محدود (5 دولارات شهرياً).

الخطوات

  1. ادخل إلى https://railway.app وسجّل بحساب GitHub.
  2. اضغط New Project ثم Deploy from GitHub repo.
  3. اختر المستودع abonasr0907-beep/-.
  4. أضف متغيرات البيئة (BOT_TOKEN, GITHUB_TOKEN, WEBHOOK_URL, ADMIN_IDS).
  5. في إعدادات التشغيل: python bot/bot.py
  6. اضبط رابط الـ Webhook كالمعتاد.
💡 ميزة Railway: لا ينام البوت أبداً في Railway، لكن الرصيد المجاني قد ينفد بسرعة إذا كان الاستخدام عالياً.
📱 الحل الرابع: Android Termux مجاني — من جوالك

Termux هو محاكي طرفية (Terminal) لأندرويد يتيح تشغيل البوت مباشرة من جوالك. مناسب للاختبار أو التشغيل المؤقت، لكن يتطلب أن يظل الجوال مفتوحاً.

الخطوات

  1. حمّل تطبيق Termux من https://f-droid.org/packages/com.termux/ (لا تستخدم متجر Play — النسخة هناك قديمة).
  2. افتح Termux ونفّذ الأوامر التالية بالترتيب:
    pkg update && pkg upgrade -y pkg install python git -y pip install python-telegram-bot[job-queue,webhooks] Pillow httpx APScheduler requests termux-setup-storage
  3. انسخ المستودع:
    cd ~/ git clone https://github.com/abonasr0907-beep/-.git afaq-bot cd afaq-bot
  4. أنشئ ملف التوكن:
    echo "BOT_TOKEN=8629398802:AAE2ndFy06GfV8qSQpd-cOKDccPUt_G05Os" > .env echo "GITHUB_TOKEN=ضع_توكنك_هنا" >> .env
  5. شغّل البوت:
    python bot/bot.py
  6. للحفاظ على عمل البوت في الخلفية:
    pkg install tmux -y tmux new -s afaq python bot/bot.py # اضغط Ctrl+B ثم D للخروج مع إبقاء البوت يعمل # للعودة: tmux attach -t afaq
⚠️ قيود Termux: يتوقف البوت عند إغلاق التطبيق أو إعادة تشغيل الجوال. يحتاج اتصال إنترنت مستمر. غير مناسب للتشغيل ٢٤/٧ — استخدمه للاختبار فقط.

منع أندرويد من إيقاف Termux

اذهب إلى إعدادات الجوال ← التطبيقات ← Termux ← البطارية ← اختر "غير محدود". فعّل "عدم تحسين البطارية" لتطبيق Termux. يمكنك أيضاً استخدام تطبيق Termux:Boot لتشغيل البوت تلقائياً عند إعادة تشغيل الجوال.

🍎 الحل الخامس: iPad Pythonista يتطلب شراء التطبيق

Pythonista هو تطبيق Python احترافي لنظام iOS (iPad/iPhone) يتيح تشغيل البوت من جهازك. سعر التطبيق حوالي 9.99 دولار.

الخطوات

  1. اشترِ وحمّل تطبيق Pythonista 3 من متجر التطبيقات.
  2. افتح Pythonista وأنشئ سكربت جديد باسم afaq_bot.py.
  3. انسخ محتوى ملف bot/bot.py من المستودع والصقه في Pythonista.
  4. ثبّت المكتبات المطلوبة (Pythonista يأتي معظمها مدمجاً، لكن قد تحتاج تثبيت httpx):
    import pip pip.main(['install', 'httpx'])
  5. قبل تشغيل البوت، احذف أي reference لـ filters.LOCATION و ReplyKeyboardMarkup إن لم تكن مدعومة، أو استخدم وضع Polling فقط.
  6. اضبط التوكن مباشرة في الكود:
    BOT_TOKEN = "8629398802:AAE2ndFy06GfV8qSQpd-cOKDccPUt_G05Os"
  7. اضغط زر التشغيل ▶️ في Pythonista.
⚠️ قيود iOS: النظام يوقف التطبيقات في الخلفية بسرعة. لا يمكن تشغيل البوت ٢٤/٧ من iOS. مناسب فقط للاختبار السريع. للحصول على تشغيل دائم، استخدم Render أو Koyeb.

🔧 استكشاف الأخطاء وإصلاحها

البوت لا يرد على الرسائل

تأكد أولاً من أن البوت يعمل بدون أخطاء — راجع سجل الأخطاء (Logs) في Render أو Koyeb. ثانياً، تحقق من أن BOT_TOKEN صحيح: أرسل طلباً إلى https://api.telegram.org/bot<TOKEN>/getMe في المتصفح — يجب أن ترى معلومات البوت. ثالثاً، إذا كنت تستخدم Webhook، تأكد من ضبطه بشكل صحيح: https://api.telegram.org/bot<TOKEN>/getWebhookInfo — يجب أن يكون last_error_message فارغاً. رابعاً، احذف الـ Webhook وأعد ضبطه إذا لزم الأمر: https://api.telegram.org/bot<TOKEN>/deleteWebhook ثم أعد ضبطه.

الصور لا تُرفع إلى الموقع

هذه المشكلة تعني أن GITHUB_TOKEN غير مضبوط أو منتهي الصلاحية. أنشئ توكن جديد من GitHub: اذهب إلى Settings ← Developer settings ← Personal access tokens ← Generate new token، وفعّل صلاحية repo. ضع التوكن في متغير البيئة GITHUB_TOKEN في Render/Koyeb.

البوصلة لا تتحدث تلقائياً

البوصلة تتحدث يومياً الساعة 6 صباحاً تلقائياً، ومزامنة الموقع تتم عند كل تحديث. إذا لم تتحدث، تأكد من أن المهمة المجدولة (job_queue) تعمل — وهذا يتطلب أن البوت يعمل بشكل متواصل أو يستيقظ بصفة منتظمة. في Render المجاني، قد لا تعمل المهمة المجدولة بسبب النوم — يمكنك تحديث البوصلة يدوياً بأمر /bousla أو /update_prices.

الأخبار لا تظهر على الموقع

الأخبار تتحدث كل 3 أيام تلقائياً. يمكنك تحديثها يدوياً بأمر /update_news أو الضغط على زر "🗞️ تحديث الأخبار" في لوحة المدير. تأكد من أن ملف offers-data/news.json موجود في المستودع ومن أن الموقع يقرأ منه.
