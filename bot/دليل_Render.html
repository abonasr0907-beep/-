⚙️ الخطوة 1: إعدادات Render

متغيرات البيئة المطلوبة

في Render → خدمتك → Environment → أضف المتغيرات التالية:

المتغيرالقيمةمطلوب؟
WEBHOOK_URLرابط خدمتك على Render (مثل https://afaq-bot-xxxx.onrender.com)✅ نعم — ضروري
GITHUB_TOKENتوكن GitHub Personal Access Token✅ نعم — لرفع الصور للموقع
BOT_TOKENمدمج في الكود (لا حاجة لضبطه)❌ اختياري

⚠️ مهم جداً عن WEBHOOK_URL

Render يعطيك رابط خدمتك بعد النشر الأول. لذلك:

  1. انشر الخدمة بدون WEBHOOK_URL أولاً
  2. بعد النشر، Render سيعطيك رابطاً مثل https://afaq-bot-xxxx.onrender.com
  3. انسخ هذا الرابط وضعه في متغير WEBHOOK_URL
  4. أعد النشر — البوت سيسجل webhook تلقائياً مع Telegram

كيف تحصل على GITHUB_TOKEN

1

اذهب إلى: https://github.com/settings/tokens

2

اضغط "Generate new token (classic)"

3

اختر صلاحية repo (كاملة)

4

انسخ التوكن (يبدأ بـ ghp_) وضعه في Render

🐳 الخطوة 2: إعدادات Docker في Render

إذا كنت تستخدم Dockerfile (الافتراضي بعد دمج PR #4):

  • Build Command: pip install -r bot/requirements.txt
  • Start Command: cd bot && python3 bot.py
  • Dockerfile Path: ./Dockerfile (افتراضي)

أو إذا اخترت "Custom Start Command" في الإعدادات:

cd bot && python3 bot.py

🔍 استكشاف الأخطاء

البوت لا يرد

تحقق من Render → Logs:

  • ابحث عن 🚀 تشغيل البوت في وضع WEBHOOK — يعني أنه يعمل
  • إذا رأيت ImportError: No module named 'requests' — لم يُدمج PR #4 بعد
  • إذا رأيت polling بدل WEBHOOK — WEBHOOK_URL غير مضبوط

الصور لا تصل للموقع

GITHUB_TOKEN غير مضبوط أو منتهي الصلاحية. جدده من GitHub Settings.
