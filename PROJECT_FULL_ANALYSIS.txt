================================================================================
أولاً: معلومات المشروع
================================================================================
- اسم المشروع: منصة أفاق الإنجاز العقارية (Afaq Al-Injaz Real Estate Platform)
- نوع المشروع والتقنيات المستخدمة:
  * موقع إلكتروني ثابت (Static Website / PWA) مدمج بنظام تصفح خفيف وميزات تفاعلية.
  * بوت تلغرام ذكي لنشر وتحديث العروض وإدارة الاستفسارات والنسخ الاحتياطي تلقائياً (Telegram Bot Automation Engine).
  * خادم برميجي خفيف API Server (HTTP / REST APIs) لإدارة بيانات الاستفسارات والزوار واللوحة الإدارية.
  * محرك ذكاء اصطناعي وأمان ذاتي (AI Guardian & SEO Automation Engine) لإدارة بيانات المحرك والـ SEO والتصليح التلقائي.
- لغات البرمجة:
  * HTML5, CSS3, JavaScript (ES6+ Vanilla JavaScript) للمواجهات والمكونات.
  * Python 3.12+ لجميع الأنظمة الخلفية (Bot, API Server, AI System, Automation Tools).
- إطار العمل المستخدم:
  * Frontend: Vanilla JS (Modular ES6 Architecture) + Leaflet.js للمخرجات الجغرافية / الخرائط + Swiper/Glassmorphism CSS UI.
  * Backend / Bot: python-telegram-bot (v20.8), Asyncio, HTTP/REST via Python Standard HTTP/WSGI servers & HTTPX/Requests.
- طريقة التشغيل والبناء:
  * Static Site: استضافة مجانية على GitHub Pages عبر Workflow تلقائي (`.github/workflows/static.yml`).
  * Bot & APIs: تشغيل الخادم والـ Bot عبر Docker (`Dockerfile`), Render (`render.yaml`), Railway (`railway.toml`), أو Procfile (`Procfile`) باستخدام `bot/start_bot.sh`.
  * السكريبتات والأدوات: سكريبتات مستقلة بـ Python لتوليد خراط الموقع (`tools/gen_sitemap.py`) وفحص المفاتيح والرموز السرية (`tools/secret_scanner.py`).

ثانياً: هيكل المشروع
================================================================================

1. مجلدات المشروع ووظائفها:
   - `.github/workflows/`: ملفات تكوين أتمتة البناء والنشر عبر GitHub Actions على GitHub Pages.
   - `ai_system/`: المحرك الذكي للنظام، يحتوي على:

     * `guardian/`: نظام الحماية ومراقبة صحة الكود وتصحيح الأخطاء تلقائياً.
     * `seo_engine/`: توليد الوسوم المحسنة SEO، الصور المصغرة، وربط IndexNow والخرائط.

     * `api_admin.py`: واجهة التحكم الإدارية، توثيق 2FA، والجلسات.
     * `visitor_api.py`: معالجة استفسارات الزوار وطلبات الحجز والخدمات.

     * `seo_automation.py` / `seo_monitor.py` / `publish_verifier.py`: أتمتة التحقق من النشر ورفع ترتيب الموقع.

     * `base.css`: القواعد الأساسية والمتغيرات.
     * `components.css`: المكونات التفاعلية (بطاقات، أزرار، نماذج).

     * `luxury.css`: لمسات التصميم الفاخر الزجاجي.

     * `style.css`: الملف المجمع لكافة الملفات السابقة.
   - `data/`: قاعدة البيانات الكائنية المحلية (JSON) مثل طلبات الخدمات `service-requests.json` والقائمين على النظام `managers.json` والإعلانات `ads.json`.
   - `docs/`: التوثيق الفني للمشروع والتقارير الأرشيفية وأدلة SEO والنشر.
   - `images/`: الصور الثابتة، شعارات الموقع، صُور العروض المحفوظة من البوت والزوار.
   - `js/`: ملفات الواجهة الأمامية الأساسية:
     * `cards.js`: بطاقات العروض الموحدة Unified Card Renderer v12 والمساعد الذكي.

     * `compare.js`: أدوات مقارنة العقارات.
     * `analytics-dashboard.js`: تحليلات الزيارات والتقارير المحلية.
     * `form-wizard.js`: معالج تقديم العقارات متعدد الخطوات.
     * `notifications.js`: نظام التنبيهات الفورية Toast.
     * `utils.js`: التابع المعاون والأدوات المساعدة ومحاذيات الرابط الاجتماعي.
     * `main.js`: ملف التهيئة والتنفيذ الرئيسي للواجهات.
     * `silo.js`, `video.js`: برمجيات الفيديو والأقسام الفرعية.
   - `offers-data/`: ملف بيانات العروض الحية الرئيسي `offers.json` والأخبار والأرقام التعريفية.
   - `tests/`: اختبارات الوحدات البرمجية (`test_guardian.py`, `test_manager_perm.py`, `test_tours.py`).
   - `tools/`: أدوات أتمتة سريعة كـ `gen_sitemap.py` لتوليد خراط الموقع و `secret_scanner.py` لفحص التسريبات.
   - Mappings & Silo Pages: (مجلدات الأقسام الفرعية مثل `lands-riyadh`, `farms-alkharj`, `center-alkharj`, `well-drilling-services`... وبداخل كل منها `index.html`).
