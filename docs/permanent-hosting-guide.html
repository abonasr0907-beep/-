🚀 الحلول الدائمة للبوت — اختر واحدة

البوت عبارة عن برنامج Python يحتاج إلى خادم يعمل باستمرار (٢٤/٧) ليبقى مستجيباً للرسائل. اختر أحد الحلول التالية حسب احتياجك:

مجاني سهل الخيار ١: Render.com (موصى به ⭐)

Render هو أفضل خيار مجاني لتشغيل البوت بشكل دائم. يوفر خطة مجانية تشغل البوت بشكل متواصل.

الخطوات:

١. اذهب إلى https://render.com وسجّل حساب مجاني (يمكنك التسجيل بحساب GitHub)

٢. اضغط "New +" ثم اختر "Background Worker"

٣. اربط مستودع GitHub: abonasr0907-beep/-

٤. املأ الإعدادات:

Name: afaq-bot Runtime: Python 3 Build Command: pip install -r bot/requirements.txt Start Command: cd bot && python3 bot.py Branch: main

٥. اضغط "Create Background Worker" — وسيبدأ البوت بالعمل خلال دقيقة!

٦. البوت سيعمل ٢٤/٧ تلقائياً، ويعيد تشغيل نفسه عند أي خطأ.

✅ المزايا: مجاني، إعداد سهل، إعادة تشغيل تلقائية، نشر تلقائي عند تحديث الكود

⚠ القيود: الخطة المجانية قد توقف البوت بعد ١٥ دقيقة من عدم النشاط (لكن البوت يستقبل رسائل تيليجرام باستمرار فلا يتوقف عادةً)

مجاني الخيار ٢: Koyeb.com

Koyeb منصة سحابية مجانية تدعم تشغيل حاويات Docker بشكل متواصل. تمنحك خطة مجانية واحدة كافية لتشغيل البوت على مدار الساعة.

الخطوات بالتفصيل:

١. اذهب إلى https://koyeb.com وسجّل حساب مجاني (يمكنك التسجيل عبر GitHub مباشرة)

٢. بعد تسجيل الدخول، اضغط على زر "Create Service" في الأعلى

٣. اختر "GitHub" كمصدر للكود، ثم اربط حساب GitHub الخاص بك

٤. اختر المستودع abonasr0907-beep/- من القائمة

٥. في قسم "Builder" اختر "Dockerfile" (لقد أضفنا Dockerfile جاهز في المشروع)

٦. في قسم "Region" اختر أقرب منطقة (مثل Frankfurt أو أي منطقة متاحة)

٧. في "Instance" اختر الخطة المجانية "Free" (eco أو free tier)

٨. اضغط "Deploy" — وسيبدأ البوت بالعمل خلال دقيقة!

💡 معلومات مهمة عن Koyeb

• الخطة المجانية تمنحك实例 (instance) واحد يعمل باستمرار

• البوت سيعمل طالما الخدمة نشطة ولا تحتاج لإعادة تشغيلها

• يمكنك مراقبة السجلات (logs) من لوحة تحكم Koyeb

• إذا توقف البوت لأي سبب، Koyeb سيعيد تشغيله تلقائياً

• كلما دفعت Push إلى GitHub، سيتم إعادة نشر البوت تلقائياً

✅ المزايا: مجاني، يدعم Docker، يعمل بشكل متواصل، إعادة تشغيل تلقائية

مدفوع مستقر الخيار ٣: خادم VPS (الأكثر استقراراً)

استأجر خادم VPS صغير (من ٥$/شهر) من أي مزود مثل:

  • Hetzner — من ٤€/شهر (موصى به، رخيص وسريع)
  • DigitalOcean — من ٤$/شهر
  • Vultr — من ٢.٥$/شهر
  • Contabo — من ٤€/شهر (مواصفات عالية بسعر منخفض)

الخطوات على الخادم:

# 1. تثبيت Python و Git sudo apt update && sudo apt install -y python3 python3-pip git # 2. تنزيل المشروع cd /opt sudo git clone https://github.com/abonasr0907-beep/- afaq cd afaq/bot # 3. تثبيت المكتبات pip3 install -r requirements.txt # 4. تفعيل البوت كخدمة نظام (تعمل ٢٤/٧) sudo cp afaq-bot.service /etc/systemd/system/ sudo systemctl daemon-reload sudo systemctl enable afaq-bot sudo systemctl start afaq-bot # 5. التحقق من الحالة sudo systemctl status afaq-bot # 6. عرض السجل المباشر sudo journalctl -u afaq-bot -f

✅ المزايا: استقرار كامل ٢٤/٧، تحكم كامل، يعيد التشغيل تلقائياً عند أي خطأ (Restart=always)

مجاني سهل الخيار ٤: تشغيل على جهازك الشخصي

يمكنك تشغيل البوت على جهازك (كمبيوتر أو لابتوب). البوت سيعمل طالما الجهاز يعمل ومتصل بالإنترنت. هذا الخيار مجاني تماماً ولا يحتاج أي تسجيل.

الخطوات على Windows:

# 1. تحميل وتثبيت Python 3.11+ من python.org # تأكد من تفعيل خيار "Add Python to PATH" أثناء التثبيت # 2. فتح Command Prompt (cmd) أو PowerShell # 3. تنزيل المشروع من GitHub git clone https://github.com/abonasr0907-beep/- afaq cd afaq\bot # 4. تثبيت المكتبات المطلوبة pip install -r requirements.txt # 5. تشغيل البوت python bot.py

الخطوات على Mac / Linux:

# 1. تثبيت Python 3.11+ (غالباً مثبت مسبقاً على Mac) # أو عبر Homebrew: brew install python@3.11 # 2. تنزيل المشروع git clone https://github.com/abonasr0907-beep/- afaq cd afaq/bot # 3. تثبيت المكتبات pip3 install -r requirements.txt # 4. تشغيل البوت مع إعادة تشغيل تلقائية chmod +x start_bot.sh ./start_bot.sh

💡 للحصول على استقرار أفضل على جهازك

• استخدم سكربت start_bot.sh الذي أضفناه — يعيد تشغيل البوت تلقائياً عند توقفه

• على Windows: يمكنك تشغيل البوت في الخلفية عبر Task Scheduler

• لا تغلق نافذة Terminal/CMD أثناء عمل البوت

• إذا أطفأت الجهاز، البوت سيتوقف — أعد تشغيله عند إعادة تشغيل الجهاز

✅ المزايا: مجاني تماماً، لا تحتاج تسجيل في أي موقع، تحكم كامل

⚠ القيود: البوت يتوقف عند إغلاق الجهاز أو فقدان الإنترنت

📄 تفعيل GitHub Pages (رابط أنظف للموقع)

للحصول على رابط موقع أنظف وأقصر، يمكنك تفعيل GitHub Pages. هذا يتطلب خطوة واحدة منك:

الخطوة ١: افتح مستودع GitHub: github.com/abonasr0907-beep/-

الخطوة ٢: اضغط على تبويب "Settings" (الإعدادات)

الخطوة ٣: في القائمة الجانبية اليسرى، اضغط على "Pages"

الخطوة ٤: تحت قسم "Build and deployment" ← "Source"، اختر "GitHub Actions"

الخطوة ٥: احفظ الإعدادات. سيقوم الـ Workflow الذي أضفناه بنشر الموقع تلقائياً.

بعد التفعيل، سيكون رابط الموقع:

https://abonasr0907-beep.github.io/-/

بعد تفعيل GitHub Pages، يمكنك تحديث رابط الموقع في البوت بتعديل ملف bot/config.json وتغيير website_url إلى الرابط الجديد.
