## 13. حالة روابط العقارات (Property Links)

### نمط الروابط:
- **الرابط الأساسي (Canonical):** `/property/{id}` — مثال: `/property/FRM-001`
- **الرابط الفعلي:** `property.html?id={id}` — مثال: `property.html?id=FRM-001`
- **آلية التحويل:** `404.html` يعترض `/property/{id}` ويعيد التوجيه إلى `property.html?id={id}`
- **الـ Canonical الديناميكي:** `property.html` يضبط canonical إلى `/property/{id}` عبر JavaScript

### منع التكرار:
- ✅ كل عقار له رابط أساسي واحد (`/property/{id}`)
- ✅ النموذج `property.html?id=` يُحوَّل تلقائياً إلى النموذج النظيف عبر 404
- ✅ canonical tag يُضبط ديناميكياً للإشارة إلى الرابط النظيف
- ⚠️ يحتاج canonical ثابت احتياطي في property.html (لحالة فشل JavaScript)
