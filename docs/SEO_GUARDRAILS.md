# SEO Guardrails — حواجز الحماية لتحسين محركات البحث

> **المرحلة:** Phase 2 §4
> **الهدف:** قواعد صارمة تمنع تدهور SEO وتضمن عدم كسر الروابط المُفهرَسة في Google.

---

## 1. القواعد الذهبية (لا تُكسر أبدًا)

### 1.1 الروابط الدائمة (Permanent Links)
- **الرابط القديم** `/property/{old_id}` يجب أن يبقى يعمل **للأبد** — حتى لو حُذف العرض.
- **الرابط الجديد** `/offer/{external_id}/{slug}` هو الأساس؛ لا يُغيّر `external_id` أبدًا.
- عند حذف عرض: عرض صفحة 410 Gone أو إعادة توجيه 301 إلى القسم — **لا 404 عشوائي**.
- لا تُغيّر `slug` بعد النشر إلا بإعادة توجيه 301 من القديم إلى الجديد.

### 1.2 ملفات محركات البحث
- `robots.txt` — لا يُعدَّل إلا بمراجعة صريحة.
- `sitemap.xml` — يُحدَّث عند كل نشر/أرشفة فقط (إضافة/حذف روابط).
- Google Search Console — لا يُلمس من البوت أو الكود تلقائيًا.

### 1.3 البيانات الوصفية (Meta)
- كل صفحة عقار لها `<title>` فريد + `meta description` + canonical URL.
- `og:image` من أول صورة للعقار.
- JSON-LD `RealEstateListing` schema على صفحة العقار.
- **لا index** على: `admin.html`، صفحات النماذج المنفصلة، صفحات الشكر، صفحات المسودة.
- **index** على: `index.html`, `property.html`, `farms.html`, `resthouses.html`, `lands.html`, `services.html`, `contact.html`.

---

## 2. قواعد المحتوى

### 2.1 ALT للصور
- كل صورة لها `alt` وصفي بالعربية (يُولَّد تلقائيًا عبر `auto_generate_alt()` إن لم يُحدد).
- الصيغة: `{نوع العقار} {المساحة} — {المنطقة} | صورة {N} | مكتب آفاق الإنجاز العقاري`.
- لا تُترك صورة بدون alt أبدًا.

### 2.2 العناوين والأوصاف
- العنوان: 10–60 حرف، يحتوي نوع العقار + المنطقة.
- الوصف: 50+ حرف، يذكر المميزات الرئيسية.
- لا تكرار عناوين متطابقة بين العقارات (يكتشفها `find_duplicates()`).

### 2.3 التنسيق الدلالي
- `<h1>` واحد لكل صفحة (عنوان العقار).
- `<h2>` للأقسام (الموقع، المميزات، التواصل).
- الصور بـ `loading="lazy"` (except first image = eager).

---

## 3. قواعد الأداء

- الخرائط: CDN فقط (MapLibre GL + Esri) — لا مفاتيح API، لا تبعيات ثقيلة.
- Lazy load للخريطة (IntersectionObserver) بعد ظهور القسم.
- الصور: lazy + أحجام مناسبة.
- لا JavaScript blocking فوق ال fold.

---

## 4. قواعد منع التكرار (Anti-Duplicate)

يكتشف `find_duplicates()` التكرار قبل النشر عبر:
1. نفس العنوان (مطبَّع) + نفس السعر
2. نفس العنوان + نفس الموقع
3. نفس رقم الجوال

النتيجة: **تنبيه فقط** — لا حذف تلقائي. المدير يقرر.

---

## 5. درجة الجودة (Quality Score)

`quality_score(listing)` تُرجع درجة 0–100:
- العنوان (15) + الوصف (15) + القسم (10) + صورة (20) + إحداثيات (10) + نص تسويقي (10) + سعر (10) + موقع (10)
- النتيجة **تحذير فقط** — لا تمنع النشر. المقصود توجيه المدراء لتحسين الجودة.

---

## 6. ما لا يُلمس (Protected)

| الملف | السبب |
|------|-------|
| `robots.txt` | حساس لمحركات البحث |
| `sitemap.xml` | يُحدَّث فقط عند نشر/أرشفة |
| `offers-data/office-data.json` | أرقام المكتب الرسمية |
| `bot/config.json` | admin_ids + إعدادات البوت |
| Google Search Console | يدوي فقط |
| `docs/HANDOFF_1.md` | سجل Phase 1 — للقراءة فقط |
